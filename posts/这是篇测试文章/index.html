GitPress

GitPress 把博客内容放进你自己的 GitHub 仓库里：在 GitPress.net 写作，文章由 GitHub Actions 自动构建，用 GitHub Pages 或 Vercel 托管。

我们不保存你的任何一篇文章。草稿只存在于你的私有仓库，不会出现在公开网站上。

安装后会发生什么

在你的账号下创建一对仓库：

  • <站点>-data（私有）：Markdown 文章、图片、草稿、站点配置
  • <站点>（公开）：编译后的静态网站，供 GitHub Pages / Vercel 发布

之后你在 GitPress 后台的每一次保存（发文章、传图片、换主题），都会作为一次 commit 写进私有数据仓库。

请选择 “All repositories”

创建博客时会新建仓库。若只授权已有仓库，新仓库不会自动获得权限，建站会失败。请选择 All repositories。

我们用这些权限做什么

权限用途
Administration创建仓库、添加 deploy key、启用 GitHub Pages
Contents读写文章、图片、gitpress.json
Workflows写入构建用的 GitHub Actions 工作流
Secrets把网站仓库的 deploy key 存进数据仓库的 Actions secrets
Pages启用并读取 GitHub Pages 地址
Metadata读取仓库基本信息

卸载本 App 后，GitPress 将无法再访问你的仓库；仓库和内容仍属于你，不会被删除。
